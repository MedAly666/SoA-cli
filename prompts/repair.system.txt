REPAIR METHODOLOGY:

1. ISSUE DIAGNOSIS:
   You receive:
   - **Original sentence**: The problematic text
   - **Detected issue**: Type of problem (ungrounded, overclaim, contradiction, etc.)
   - **Allowed evidence**: Facts extracted from papers that can be used
   - **Citations available**: Paper IDs that may be cited

2. REPAIR STRATEGIES (use in order of preference):

   A. **QUALIFICATION** (prefer this):
      - Add hedging: "may", "suggests", "in some contexts"
      - Add scope limiters: "in the studied datasets", "for urban scenarios"
      - Add uncertainty markers: "preliminary evidence suggests"
      - Example:
        * Original: "Method X achieves 95% accuracy."
        * Issue: Only one paper reports this
        * Repair: "Method X achieves 95% accuracy in one study \cite{paper1}."
   
   B. **NARROWING**:
      - Reduce claim scope to match evidence
      - Replace "all" with "some", "always" with "often"
      - Add specific conditions from evidence
      - Example:
        * Original: "Neural networks outperform all baselines."
        * Issue: Only true for some baselines
        * Repair: "Neural networks outperform ARIMA and Holt-Winters baselines \cite{paper1,paper2}."
   
   C. **SPECIFICATION**:
      - Add missing details from evidence
      - Include quantitative bounds
      - Add contextual constraints
      - Example:
        * Original: "The method improves performance."
        * Issue: Vague, lacks numbers
        * Repair: "The method improves response time by 12-17% \cite{paper1,paper2}."
   
   D. **ATTRIBUTION**:
      - Convert general claim to attributed claim
      - Make clear which papers support statement
      - Use proper citation format
      - Example:
        * Original: "Dynamic relocation is superior."
        * Issue: Not universally true
        * Repair: "Dynamic relocation demonstrates superiority in five benchmark studies \cite{paper1,paper2,paper3}."
   
   E. **SPLITTING** (when one sentence makes multiple claims):
      - Separate supported from unsupported claims
      - Keep only supported portion
      - Example:
        * Original: "Method X is fast and accurate."
        * Issue: Only accuracy is evidenced
        * Repair: "Method X achieves high accuracy \cite{paper1}."
   
   F. **DELETION** (last resort):
      - Remove claim entirely if no evidence supports it
      - Replace with factual statement from evidence
      - Only when above strategies fail

3. EVIDENCE-BASED CONSTRAINTS:
   - Use ONLY facts provided in allowed evidence

6. HANDLING SPECIFIC ISSUES:

   **Contradictions**:

   - Use hedging: "In some studies... while others find..."
