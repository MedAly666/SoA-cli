# Artifacts Directory Organization

All outputs generated by the SOA-CLI system are organized into dedicated subfolders for better management and clarity.

## Directory Structure

```
artifacts/
├── states/               # Pipeline state files
│   ├── initial_state.json       # Input state (for debugging)
│   └── final_state.json         # Complete final state with all results
│
├── prisma/              # PRISMA methodology reports
│   ├── prisma_report.json       # Statistics and counts for each stage
│   ├── prisma_flow_diagram.md   # PRISMA flow diagram (Mermaid format)
│   └── excluded_papers.json     # Detailed exclusion log with reasons
│
├── reader/              # Per-paper parsed structures
│   └── {paper_id}.json         # Parsed paper sections (abstract, intro, etc.)
│
├── extracted/           # Per-paper extracted facts
│   └── {paper_id}.json         # Extracted key facts from each paper
│
├── critic/              # Per-paper quality assessments
│   └── {paper_id}.json         # Quality and relevance assessments
│
├── clusters/            # Paper clustering outputs
│   ├── preclusters.json        # Raw similarity-based clusters
│   ├── clusters.json           # Interpreted thematic clusters
│   └── input.json              # Cluster agent input
│
├── synthesis/           # Cross-paper synthesis
│   ├── input.json              # Synthesis agent input
│   ├── synthesis.json          # Cross-paper insights and patterns
│   └── synthesis_output.json   # Additional synthesis outputs
│
└── soa/                 # State of the Art outputs
    ├── state_of_the_art.tex        # Draft LaTeX
    ├── state_of_the_art_final.tex  # Final verified LaTeX
    ├── state_of_the_art_final.md   # Markdown version
    ├── state_of_the_art_final.docx # Word version
    ├── hallucination_report.json   # Verification results
    ├── repair_failure.json         # Unrepairable issues (if any)
    └── _writer_input.json          # Writer agent input

```

## File Descriptions

### States Folder
- **initial_state.json**: Snapshot of the pipeline state at start (papers, contract, config)
- **final_state.json**: Complete final state including all results, errors, and metadata

### PRISMA Folder
- **prisma_report.json**: Detailed PRISMA report with counts for identification, screening, eligibility stages
- **prisma_flow_diagram.md**: Visual PRISMA flow diagram in Mermaid format (can be rendered in GitHub/VSCode)
- **excluded_papers.json**: List of all excluded papers with specific exclusion reasons

### Per-Paper Folders (reader/, extracted/, critic/)
Each paper gets 3 files across these folders:
- **reader/{paper_id}.json**: Raw parsed paper structure
- **extracted/{paper_id}.json**: Extracted facts relevant to research theme
- **critic/{paper_id}.json**: Quality assessment and relevance scoring

### Clustering Folder
- **preclusters.json**: Raw FAISS similarity-based clusters
- **clusters.json**: LLM-interpreted thematic clusters with names and descriptions
- **input.json**: Input data for cluster agent

### Synthesis Folder
- **synthesis.json**: Cross-paper synthesis addressing core research questions
- **synthesis_output.json**: Additional synthesis outputs
- **input.json**: Input data for synthesis agent

### SOA Folder
- **state_of_the_art.tex**: Draft LaTeX generated by writer agent
- **state_of_the_art_final.tex**: Final verified and repaired LaTeX
- **hallucination_report.json**: Hallucination detection results
- **repair_failure.json**: Issues that couldn't be automatically fixed

## Usage

### Accessing State Files
```bash
# Check pipeline stage
cat artifacts/states/final_state.json | jq '.pipeline_stage'

# Check for errors
cat artifacts/states/final_state.json | jq '.errors'
```

### Reviewing PRISMA Reports
```bash
# View PRISMA statistics
cat artifacts/prisma/prisma_report.json | jq '.'

# Check exclusion reasons
cat artifacts/prisma/excluded_papers.json | jq '.excluded_at_screening[0:5]'
```

### Inspecting Paper Processing
```bash
# List processed papers
ls artifacts/reader/*.json | wc -l

# Check specific paper extraction
cat artifacts/extracted/paper_name.json | jq '.key_facts'
```

### Reviewing Clusters
```bash
# View cluster assignments
cat artifacts/clusters/clusters.json

# Check synthesis results
cat artifacts/synthesis/synthesis.json | jq '.core_question_syntheses'
```

## Maintenance

- Old artifact files from previous runs are automatically preserved
- The system creates these directories automatically when needed
- You can safely delete individual folders to force reprocessing of specific stages
- Keep `artifacts/states/final_state.json` to resume interrupted runs

## Version Control

It's recommended to:
- ✅ **Commit**: PRISMA reports, final SOA outputs
- ⚠️ **Review before committing**: State files (may contain large data)
- ❌ **Don't commit**: Individual paper extractions (too many files)

Consider adding to `.gitignore`:
```
artifacts/reader/
artifacts/extracted/
artifacts/critic/
artifacts/states/initial_state.json
```
