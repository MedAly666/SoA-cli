# Artifact Organization - Change Summary

## Overview

All artifacts generated by SOA-CLI are now organized into dedicated subfolders within the `artifacts/` directory for better organization and clarity.

## What Changed

### New Directory Structure

**Before:**
```
artifacts/
├── initial_state.json          # ❌ Root level
├── final_state.json            # ❌ Root level
├── prisma_report.json          # ❌ Root level
├── prisma_flow_diagram.md      # ❌ Root level
├── excluded_papers.json        # ❌ Root level
├── reader/
├── extracted/
├── critic/
├── clusters/
├── synthesis/
└── soa/
```

**After:**
```
artifacts/
├── states/                      # ✅ NEW: Pipeline states
│   ├── initial_state.json
│   └── final_state.json
├── prisma/                      # ✅ NEW: PRISMA reports
│   ├── prisma_report.json
│   ├── prisma_flow_diagram.md
│   └── excluded_papers.json
├── reader/
├── extracted/
├── critic/
├── clusters/
├── synthesis/
└── soa/
```

## Benefits

✅ **Better Organization**: Related artifacts grouped together  
✅ **Easier Navigation**: Clear purpose for each subfolder  
✅ **Cleaner Root**: No loose files in artifacts/ root  
✅ **Scalability**: Easy to add new artifact categories  
✅ **Clarity**: Immediately understand what each folder contains

## Migration

Existing artifact files were automatically moved:
- `initial_state.json` → `states/`
- `final_state.json` → `states/`
- `prisma_report.json` → `prisma/`
- `prisma_flow_diagram.md` → `prisma/`
- `excluded_papers.json` → `prisma/`
- `synthesis_output.json` → `synthesis/`

## Backward Compatibility

⚠️ **Breaking Change**: Scripts or tools that hardcode old artifact paths will need updates.

**Update your scripts:**
```bash
# Old
cat artifacts/final_state.json

# New
cat artifacts/states/final_state.json
```
